### HIGH

**H1 · A symlinked artifact walks through the my-office quarantine.** *(security · Fable;
coordinator re-ran the probe; converges with Codex CX-2 and Fable CP-4 on "a path check that
follows symlinks")* CONFIRMED HIGH. `myoffice.py:116-121` records the pull delta as
`git diff --name-only before after -- canonical`, but `discover_artifacts` (`schema.py:508-511`,
`rglob`) and the withhold check (`compile.py:209`, `content_hash`) read *through* symlinks. Push 1:
`canonical/hooks/evil.md -> ../../payload/evil.md` is quarantined by the hash of v1. Push 2 edits
only `payload/evil.md` — outside the pathspec, so nothing is recorded; the on-disk hash is now v2,
not pending; `do_my_sync` auto-recompiles and places the hook into `~/.claude/settings.json`;
`my-office review`'s `reconcile` prunes the stale v1 record so the user sees an empty quarantine.
Probe: `push2: withheld=[] · PLACED pwned-evil-v2`. The quarantine's own threat model
(`quarantine.py:317-320`) is a hostile or compromised shared remote, so the trigger is in scope.
Fix: refuse symlinks in `discover_artifacts` / `all_gated_in` (mirror
`_assert_staging_contained`, `compile.py:343-346`) and fail closed when a pull touches one. **#285.**

**H2 · `ratchet` executes engine-authored code on the host, unconfined.** *(critical-path ·
Fable; converges with resilience RES-1/RES-2 (Sonnet) on the same file)* CONFIRMED HIGH.
`ratchet.py:96-99` runs the user's evaluator with `shell=True`, no `env=`, no sandbox, inside the
worktree the engine just wrote to (`:252` propose → `:266` evaluate). An engine that writes
`conftest.py` gets its code run as the user with the full host environment and open network — the
scrubbed env and Codex's no-network sandbox are defeated one line later. `ratchet.md:66` claims "a
runaway or prompt-injected proposal harms only a disposable worktree"; `ratchet.py:13-16` calls the
evaluator immutable. Never raised r1–r4; not covered by #237 (egress only). Same file, same fix PR:
`_git` (`:155-156`) has no `timeout=` and none of `gitutil.GIT_ENV`'s non-interactive hardening
(a `commit.gpgsign` user with an expired agent hangs the loop forever), and `_evaluate` has no
process-group kill, so evaluator children survive a timeout and race `_revert`. **#286.**

**H3 · The #265 scanner fix is quadratic; every egress path hangs on a long quote-free line.**
*(critical-path · Fable; refuter B upgraded MED→HIGH; coordinator re-timed)* CONFIRMED HIGH.
`gates.py:430-432` resumes the rescan at `match.start(3)`, inside the consumed value, whose token
`[^\s'"]{6,}` runs to the next whitespace or quote — on a separator-dense line each of O(n)
candidates rescans O(n). Coordinator timing: 25 KB 0.18 s, 64 KB 1.10 s, 129 KB 4.19 s (×3.9 per
doubling); refuter: 245 KB CSS-shaped 18 s; pre-fix `finditer` (`603d5de^`) 512 KB in 0.075 s. Every
CLI-doer dispatch scans every tracked file up to the 50 MB cap (`cli_doer.py:346-358`); a 1 MB
minified asset ≈ 6 min, 3 MB ≈ 1 h, with no output and no timeout. Fails closed by hanging, which
re-opens #233 in a new form. Cheapest fix in the run: bound the value token (`{6,256}`) or scan per
line, plus a perf regression test. Note the performance reviewer's "scanner is linear" negative was
measured on prose-shaped input only and is contradicted here. **#287.**
